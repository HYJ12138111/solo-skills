# 体育学科高水平论文写作

> 好的体育科学论文不是汇报你做了什么，而是**说服读者为什么这很重要**。

---

## 一、总体写作哲学

### 三条黄金法则

1. **一致性法则**：所有IMRaD段落按相同顺序组织主题。"像写代码——变量在全文中保持一致"

2. **倒三角写作法**：每段开头先给结论/判断，再展开论证。读者不需要悬念。

3. **双重读者意识**：同时写给同行审稿人（要严谨）和一线从业者（要可理解）。体育科学的特殊性在于实践者和研究者高度重叠。

### 写作顺序（不是从头写）

```
数据可视化 → Results → Methods → Discussion → Introduction → Abstract → Title
```

**为什么**：先确认发现了什么（图表），再写做了什么→发现了什么→意味着什么→为什么研究这个。

## 二、IMRaD 逐节精要

### 2.1 Introduction（引言）— 漏斗结构

**段落数**：3-5段，不超过800字

**论证模型：Problem-Gap-Hook**

```
第1段：大背景 → 为什么这个领域重要
第2段：已有研究 → 已知什么，但有什么局限（Gap）
第3段：你的方案 → 如何填补这个空白（Hook）
第4段（可选）：研究假设 + 预测（显式写出）
```

**Chow 的模式**：她几乎总是用 "What-Why-How" 三段论组织引言——定义概念(What)→理论依据(Why)→实施路径(How)。这种结构让复杂理论变得可操作。

**常见错误**：
- ❌ 引言讨论的内容最终论文没有回应
- ❌ 背景太大太空（"体育对健康很重要"级别）
- ✅ 每个背景句都在为你的研究问题铺路

### 2.2 Methods（方法）— 菜谱结构

**一句话原则**：另一个研究者读完后能完整复现你的研究。

**必须子标题**：
- 研究设计（为什么选这个设计？）
- 参与者（纳入/排除标准、样本量依据）
- 数据采集（仪器、流程、信效度）
- 数据分析（统计方法、效应量、软件版本）

**Chow 的特征**：她在方法部分就区分了 NLP 组和 LP 组的约束设计——展示的不是"我们教了什么"而是"学习环境的设计参数"。这种写法把方法变成了理论的操作化。

**常见错误**：
- ❌ 只说用了什么统计方法，不说为什么
- ❌ 缺少样本量计算依据
- ✅ 每个方法选择都要有理由

### 2.3 Results（结果）— 层级呈现

**呈现优先级**：Figure > Table > 正文文字

```
第1段：最重要的发现（开门见山）
随后段落：按假说/变量的顺序，逐一报告
```

**关键规则**：
- Results 只说 **what**（发生了什么），不说 **why**（为什么）——那是 Discussion 的事
- 每个结果必须与 Methods 中的分析计划对应
- 报告效应量（Cohen's d / η²）+ 置信区间，不只给 p 值

**Chow 的多层分析特征**：她的结果通常分3层——(1)个体运动学变化 (2)比赛表现指标 (3)班级层面比较。这创造了一个从微观到宏观的完整证据链。

### 2.4 Discussion（讨论）— 倒漏斗结构

**第1段必须**：直接回答"假说是否得到支持？"不要铺垫。

**段落结构**（每段遵循）：
```
主题句（主张）→ 你的证据 → 文献对照 → 解释机制 → 过渡
```

**Chow 的平衡写法**：她从不只说 NLP 好话。典型句式："These findings suggest that NLP can... However, it is important to note that linear pedagogy approaches also have a role to play..." 这种**不贬低对立面的平衡语气**是高水平论文的标志。

**局限性处理**：散布在各段落中，而非单独一个"Limitations"段。每个局限性都要跟着 "尽管如此，这意味着什么"。

**常见错误**：
- ❌ 讨论第1段在复述背景→应该直接回答问题
- ❌ 只引支持自己的文献→必须引用并解释矛盾的文献
- ❌ 局限性段写成了自我批评→应该讨论"尽管如此，我的发现仍然成立"

## 三、Chow Jia Yi 写作模式精要

### 3.1 标志性结构：What-Why-How

```
What（是什么）：定义非线性教学法的核心原则
Why（为什么）：生态动力学 + 动态系统理论的证据
How（怎么做）：在真实体育课中的实施策略 + 案例
```

这是她2021年PESP论文的骨架，也是她所有教学论文的底层结构。**你的论文也可以套这个骨架**——先定义核心概念→再给理论/实证依据→再展示实践路径。

### 3.2 理论→设计原则→教学通道 三层映射

Chow 从不只讲理论。她总是把抽象概念映射到可操作的教学行为：

| 理论原则 | 设计原则 | 教学通道 |
|---------|---------|---------|
| 生态动力学 | 代表性学习设计 | 修改游戏规则/场地 |
| 自组织 | 约束操控 | 调整器材/人数/空间 |
| 功能性变异 | 鼓励探索 | 不纠正"非标准"动作 |
| 知觉-行动耦合 | 不分解练习 | 保持完整游戏形式 |

**你的论文可以效仿**：每个理论概念都要对应一个具体的设计操作。

### 3.3 证据驱动 + 新加坡情境落地

Chow 的每篇应用论文都有一个固定的双层论证：
1. 国际文献的普遍证据（理论层面）
2. 新加坡体育课程的具体需求（应用层面）

这种"全球理论→本地问题"的论证路径是她论文说服力的关键。

### 3.4 措辞特征

- **不绝对化**："may""could""suggest"而非"prove""demonstrate"
- **用数据说话**：每个主张都有引用或数据支持
- **承认局限性但不停留在局限性**："Future research could..."而不是"This study was limited by..."
- **合作型署名**：频繁与 Davids/Button/Renshaw/Komar 合作——构建稳定的学术声音

## 四、段落论证模式

### 标准论证段（PEEL）

```
P (Point)：主题句——这一段要说什么
E (Evidence)：你的数据或引用
E (Explanation)：为什么这个证据支持你的观点
L (Link)：链接回论文核心问题，或过渡到下一段
```

### 批判论证段（承认-回应）

```
1. 承认对立观点或矛盾发现
2. 解释为什么会存在这种差异（方法？样本？情境？）
3. 说明为什么你的解释在这种情况下更合理
4. 回扣你的核心论点
```

Chow 在处理 NLP vs 传统教学法的争论时，就是这种论证的典范。

## 五、常见论文类型模板

### 实验研究（RCT/准实验）

```
Introduction: Problem-Gap-Hook → 假说
Methods: 设计→被试→流程→分析
Results: 主效应→交互→简单效应→效应量
Discussion: 假说验证→与文献对话→机制解释→实践意义
```

### 综述/理论论文

```
Introduction: 为什么现在需要这篇综述
Body: 按主题/时间/理论流派组织，每个section有明确的take-away
Discussion: 综合→研究议程→对实践的启示
```

### 教学实践论文

```
Introduction: 教学问题→现有方法的局限→NLP作为解决方案
Body: What(核心原则)→Why(理论/证据)→How(案例+操作步骤)
Discussion: 实施挑战→教师培训启示→未来方向
```

## 六、语言与措辞

### 学术英语精要

| 避免 | 使用 |
|------|------|
| prove / demonstrate | suggest / indicate / provide evidence for |
| always / never | typically / in most cases |
| very / extremely / really | 用具体数据代替 |
| This study is limited | These findings should be interpreted considering... |

### 体育科学常用句式

```
引言: "There is growing evidence that..." "However, less is known about..."
方法: "Participants were recruited from..." "A [design] was employed to examine..."
结果: "[Variable] was significantly greater in [condition] (M±SD; p=, d=)"
讨论: "Consistent with [文献], our findings suggest..." 
      "In contrast to [文献], we observed... This discrepancy may be due to..."
```

### 转场词（增加连贯性）

| 功能 | 词汇 |
|------|------|
| 递进 | Furthermore, Moreover, In addition |
| 对比 | However, In contrast, Conversely, Whereas |
| 因果 | Therefore, Consequently, As a result |
| 举例 | For instance, Specifically, To illustrate |
| 总结 | Taken together, Collectively, In summary |

## 七、投稿前自检清单

### 结构
- [ ] Introduction 最后一段明确了研究目的/假说
- [ ] Methods 按"菜谱"逻辑组织，可复现
- [ ] Results 和 Methods 的分析计划一一对应
- [ ] Discussion 第1句直接回答了假说
- [ ] 各节主题顺序一致

### 论证
- [ ] 每个主张都有证据（数据或引用）
- [ ] 引用了矛盾文献并解释了分歧
- [ ] 局限性已讨论且评估了影响
- [ ] 实践启示具体、可操作

### 语言
- [ ] 避免绝对化措辞（prove, always, never）
- [ ] 段落长度适中（150-250词）
- [ ] 转场词使用恰当
- [ ] 缩写首次出现时定义了
