# Solo Skills

个人 Claude Code 技能包，通过插件市场安装后自动更新。

## 包含技能

- **学术写作**: nature-writing, nature-polishing, nature-citation, nature-response, nature-reviewer, nature-data, sports-science-writing
- **论文阅读**: nature-reader, paper-analyze, paper-search, nature-academic-search
- **图表专利**: nature-figure, nature-paper2ppt, nature-paper-to-patent
- **投资交易**: a-stock-data, vibe-trading, serenity-perspective, chow-perspective
- **工具**: prompt-engineering, nuwa, start-my-day

## 安装

```bash
claude plugin install solo-skills@solo-skills
```

## 更新

Claude Code 启动时自动检查更新，或手动：

```bash
claude plugin marketplace update
claude plugin update solo-skills
```
